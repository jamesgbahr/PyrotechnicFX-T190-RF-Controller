PyrotechnicFX T190 Sender v1.6.3 — Windows build correction

CAUSE OF THE v1.4.2 FAILURE
The uploaded traceback shows Windows error 206 while PlatformIO copies deeply nested RadioLib example folders into a deeply nested project .pio directory. The dependency itself was downloaded; the destination path became too long.

FIX IN THIS RELEASE
platformio.ini now sets:

workspace_dir = ${sysenv.USERPROFILE}/.pfxpio/tx

This relocates build products and libdeps to a short path independent of the Downloads/extraction folder depth.

FIRST BUILD
Run scripts\clean_build.bat

OUTPUT
Firmware will be created beneath:
%USERPROFILE%\.pfxpio\tx\build\t190_sender\firmware.bin
